## DDL 설정 확인 범위

2026-10-04 실행 중인 systemd 백엔드 PID의 환경과 실행 인자, 실제 JAR에 포함된 설정을 읽기 전용으로 확인했습니다.

- `SPRING_PROFILES_ACTIVE=prod`가 적용되어 있습니다.
- 실행 JAR의 공통 `application.yaml`에 `spring.jpa.hibernate.ddl-auto: update`가 있고, `prod` 구간은 이 값을 재정의하지 않습니다.
- `SPRING_JPA_HIBERNATE_DDL_AUTO`, `SPRING_JPA_PROPERTIES_HIBERNATE_HBM2DDL_AUTO`, 대응 실행 인자에 별도 값이 없습니다.
- `SPRING_CONFIG_LOCATION`, `SPRING_CONFIG_ADDITIONAL_LOCATION`, `SPRING_CONFIG_IMPORT`, `SPRING_CONFIG_NAME`, `SPRING_APPLICATION_JSON` 재정의가 없습니다.
- `JAVA_TOOL_OPTIONS`, `JDK_JAVA_OPTIONS`, `_JAVA_OPTIONS`가 없으며 JVM 옵션을 통한 추가 재정의도 없습니다.
- 프로세스 작업 디렉터리, `config`, `config/*`의 외부 애플리케이션 설정 파일이 없습니다.

따라서 현재 운영은 공통 `update` 설정을 사용합니다. 이 확인은 향후 `validate` 전환이나 DB 초기화가 이미 완료되었다는 의미가 아닙니다. 오픈 전 순서는 [DB 운영 안내](database/README.md)에 따릅니다.
